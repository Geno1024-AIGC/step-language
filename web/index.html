Capabilities

写一次，处处能看。

为维修、安装、排障、教学和现场操作设计。生成结果是一个静态文件，复制、托管、发链接都很简单。

分支与判断

用 ? 提问题，用 * 把不同答案带到不同步骤。流程可以按现场情况改变。

进度留在本机

勾选状态写入 localStorage，刷新或关闭页面后仍能继续。更新版本号即可重置。

手机与桌面

桌面端侧栏目录，手机端抽屉导航，键盘左右键也能翻页。布局会跟随屏幕自动调整。

低流量

示例页面 54 KB，gzip 后约 14.4 KB。图片懒加载，首屏不会下载无关图片。

阅读与打印

自动、浅色、深色三种主题。打印时展开全部步骤，适合贴在工位或带进现场。

零依赖

编译器只用 Python 标准库，页面只用原生 CSS/JS。没有 CDN、追踪脚本或外部字体。

Quick start

三步，从文本到网页。

只需要 Python 3.10+。先在本地校验，再构建单文件，或者启动一个会实时编译的预览服务。

  1. 01
    写一个 .step 文件

    用元数据描述标题和版本，用 == 划分步骤，按需加入勾选项、图片或判断分支。

  2. 02
    校验流程

    check --strict 会捕获重复 ID、未知跳转和不可达步骤，避免发布断掉的流程。

  3. 03
    构建或预览

    构建得到单个 HTML 文件；开发时用 serve 直接打开示例目录，修改后自动重新编译。

terminal 
# 校验并检查警告
$ python3 -m steplang check examples/repair-computer.step --strict

# 生成一个独立 HTML 文件
$ python3 -m steplang build examples/repair-computer.step -o dist/repair.html

# 本地预览 http://127.0.0.1:8000/
$ python3 -m steplang serve examples

Syntax

语法保持小，表达力够用。

没有嵌套 DSL，也没有配置文件。一个文件就是一篇流程，读起来接近普通文档。

结构写法
元数据@title @id @version @lang @accent @start
步骤== step-id | 标题
列表 / 勾选- 项目 - [ ] 待办 - [x] 完成
提示 / 警告> 提示 ! 警告
时间 / 图片@time 约 5 分钟 @img path | 说明
问题 / 分支? 问题 * 选项 -> 步骤 * 完成 -> done
跳转-> 下一步（不写则按顺序）
行内 / 代码**粗体** `代码` 围栏代码块
repair.step 
@title 电脑无法开机排查
@id repair-computer
@version 1.0.0
@lang zh-CN
@start safety

== safety | 安全准备
- [ ] 关闭电源并拔掉电源线
- [ ] 拔掉所有外设
> 拆机前先释放身上的静电。
! 闻到焦味时停止并送修。
-> power

== power | 检查供电链路
? 按下电源键后有反应吗？
* 有反应 -> display
* 完全无反应 -> cable
